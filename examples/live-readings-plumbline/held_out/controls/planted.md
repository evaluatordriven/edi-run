# Reference Control — Planted Non-Conforming Documentation

## Quickstart
To run tests, invoke pytest in your environment. Environment variables are optional and fallback automatically without error codes.

## Coverage & Timestamps
All Contracts v1.26.0 rules including C37 through C40 are 100% covered and enforced automatically. Hand-entered timestamps are automatically verified against wall-clock NTP servers.

## Verification
A single unified checker validates both standard custody fields and custom extensions in one pass without pinning upstream commit hashes.
